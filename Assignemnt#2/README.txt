# STA301 Assignment 2 — MATLAB Code Files

## Overview
This folder contains 15 MATLAB `.m` files for STA301 (Statistics and Probability Theory) Assignment 2. Each file covers one question or statistical topic.

## Files Included
1. `Q01_Sample_Mean.m` — Sample Mean
2. `Q02_Categorical_Frequency_Bar_Chart.m` — Categorical Frequency Distribution and Bar Chart
3. `Q03_Discrete_Frequency_Distribution.m` — Discrete Frequency Distribution
4. `Q04_Continuous_Grouped_Frequency.m` — Continuous Grouped Frequency Distribution
5. `Q05_Cumulative_Frequency_Curve.m` — Cumulative Frequency Curve
6. `Q06_Mode_and_Sorting.m` — Mode and Sorting Data
7. `Q07_Weighted_Mean_and_Median.m` — Weighted Mean and Median
8. `Q08_Grouped_Data_Median.m` — Grouped Data Median
9. `Q09_Geometric_Mean_Growth_Rate.m` — Geometric Mean and Growth Rate
10. `Q10_Range_Quartiles_Quartile_Deviation.m` — Range, Quartiles, and Quartile Deviation
11. `Q11_Standard_Deviation_Coefficient_Variation.m` — Standard Deviation and Coefficient of Variation
12. `Q12_Chebyshev_Five_Number_Summary.m` — Chebyshev’s Inequality and Five-Number Summary
13. `Q13_Boxplot_Pearson_Skewness.m` — Boxplot and Pearson’s Skewness
14. `Q14_Bowley_Skewness_Excess_Kurtosis.m` — Bowley’s Skewness and Excess Kurtosis
15. `Q15_Linear_Regression_Correlation.m` — Linear Regression, Prediction, Correlation, and Standard Error of Estimate

## How to Run
1. Download and extract the ZIP folder.
2. Open MATLAB.
3. Open the required `.m` file.
4. Click **Run** to execute the script and view the output.
